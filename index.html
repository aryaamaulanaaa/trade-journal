Sinkron laptop ↔ HP (opsional, sekali setup)
  1. Buat project gratis di supabase.com.
  2. SQL Editor → tempel isi supabase-setup.sql → Run.
  3. Project Settings → API: copy Project URL dan anon public key ke kolom di atas.
  4. Di HP: buka app yang sama, isi dua kolom itu sekali. Selesai — data otomatis menyatu.

Anon key memang publik untuk client; siapa pun yang tahu URL+key bisa mengakses tabel. Jangan simpan info sensitif. Kalau ragu, pakai mode lokal + export CSV.

Cara pakai (3 baris)
  1. Isi tanggal, pair, arah, entry, stop. Target opsional. Exit diisi saat trade selesai.
  2. R dihitung otomatis: (exit − entry) / (entry − stop), dibalik untuk short.
  3. Centang "melanggar aturan" setiap kali kamu tidak mengikuti rencana. Itu metrik paling penting.
